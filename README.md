# 即时零售图片工作台

面向美团闪购、淘宝闪购等即时零售业务的商品图片生产工具。输入商品资料和参考图后，工作台按固定 7 图结构完成策划、生成、中文排版、内部质检和 ZIP 导出。

## 核心流程

1. 上传真实商品参考图，商品包装始终作为生成依据。
2. 填写商品名称、平台类目、品牌、SKU、售卖规格、包装、口味等客观资料。
3. 选择平台尺寸、视觉风格和并发数。
4. 一键生成 7 张图，可暂停、继续、失败重试或单张重做。
5. 在内部质检区核对尺寸、资料完整性、包装一致性和违规文案风险。
6. 按 SKU 导出命名稳定的 PNG 图片和 `manifest.json`。

## 固定 7 图

| 序号 | 图片位 | 作用 |
| --- | --- | --- |
| 01 | 白底主图 | 完整、居中展示实际售卖商品 |
| 02 | 商品正面 | 强化包装、品牌与规格识别 |
| 03 | 核心卖点 | 展示由已确认商品资料生成的简短卖点 |
| 04 | 细节展示 | 放大包装或产品结构细节 |
| 05 | 使用场景 | 生成符合品类的真实消费场景 |
| 06 | 规格信息 | 用确定性中文排版展示销售属性 |
| 07 | 详情长图 | 汇总商品信息、卖点和使用场景 |

消费者可见图片不会写入“待补充”“内部质检”“资料检查”等内部流程文案。价格、具体优惠券、二维码、水印、联系方式和其他平台标识会被规则拦截或要求人工复核。

## 商品池知识

工作台的类目引擎来自对本地 `主档资料商品池.xlsx` 的全量结构化扫描，而不是抽样：

- 109,441 条商品记录、40 个字段
- 美团：42 个一级类目、1,659 条完整类目路径
- 淘宝闪购：39 个一级类目、1,862 条完整类目路径
- 京东到家：46 个一级类目、2,750 条完整类目路径
- 归纳为 23 种图片策划原型，一级类目全部有映射

运行时使用精简知识文件 [`public/knowledge/retail-category-knowledge.v1.json`](public/knowledge/retail-category-knowledge.v1.json)，支持完整类目搜索、类目专属资料字段、场景建议和安全回退。原始 77MB 工作簿不打包进前端。

完整扫描脚本、19MB 审计明细和统计摘要保存在本机工作区的 `research/product-pool-2026-08-11/`，前端仓库只携带运行所需的精简知识文件。

## 平台规则

内置美团方图预设采用 600×600px，单图上限 5MB，并在生成和质检阶段要求商品完整、居中、清晰且与实际售卖商品一致。规则依据：[美团闪购商品信息发布管理规范](https://rules-center.meituan.com/m/detail/guize/681)。

淘宝闪购预设标记为可编辑的业务默认值，正式上传前应按当前商家后台提示复核尺寸和文件限制。

## 本地运行

```bash
npm ci
npm run dev
```

打开 Vite 输出的本地地址，在“接口设置”中配置可用的图片生成接口、API Key 和模型。项目沿用原工具的 OpenAI 兼容接口及已有供应商配置能力。

用于本地联调的模拟接口：

```bash
npm run mock:api
```

## 验证

```bash
npm test
npm run build
```

测试覆盖类目匹配、商品资料校验、7 图策划、平台尺寸、持久化、队列、中文合成、质检和 ZIP 导出。

## 数据与隐私

- 项目、图片和配置默认保存在浏览器本地 IndexedDB。
- 只有执行生成时，参考图和提示词才会发送到所配置的模型服务。
- 导出包只包含当前商品的最终 7 图和交付清单；内部质检信息不会合成到消费者图片中。
